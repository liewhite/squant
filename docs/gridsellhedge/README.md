# ETH 期权 网格卖方 + 动态阈值备兑对冲

卖出 30 天到期的 ETH 期权，用一张 100 整数网格滚动卖出，并对每个空头期权按行权价做带动态阈值的 1:1 备兑对冲。
**驱动方式：每 3 秒轮询一次（非逐笔高频）；对冲用 maker 挂单执行（BBO 外 0.01%，撤单重挂）。**

代码：`src/main/scala/strategy/strategies/gridsellhedge/`
运行：`sbt "runMain strategy.strategies.gridsellhedge.backtest.GridSellHedgeBacktest"`

---

## 规则 1 — 网格卖出 (`logic/OptionGrid.scala`)

- 卖的都是**卖出时刻 + 30 天**到期的期权。
- **每 3 秒轮询**：维护当前价**上下最近两档**各有一份空头——上档卖 call、下档卖 put（价 2350 → call@2400 + put@2300）。缺哪一侧就补卖（`bracket`）。
- 价格漂移进新的 100 区间后，新的上下档被补上；旧档持有到期后释放，可再次被补卖。**单档单持仓**。
- **到期**：按内在价值结算，释放该档；价格再次进入可重卖。

## 规则 2 — 动态阈值行权价备兑对冲 (`logic/DynamicHedgeBand.scala` + `backtest/GridSellHedgeSim.scala`)

每个空头期权一份独立状态，在**风险方向**（短 call 看价上穿 K、短 put 看价下穿 K）上，**每 3 秒轮询**、**maker 挂单执行**：

- **开仓（越过行权价即对冲）**：价越过行权价（风险距离 `d ≥ 0`）且无挂单 → 在 **BBO 外 0.01% 挂 maker 单**（短 call→买、短 put→卖）；已有挂单则撤单重挂（追价）。**成交才真正建仓**。
- **平仓（回落超过阈值）**：价回落到行权价安全侧、超过离场阈值（`d ≤ −threshold`）→ 挂平仓 maker 单了结备兑。
- **每次越过行权价放大阈值**：开仓成交时离场阈值 **×1.2**。
- **时间衰减**：未持对冲时每小时阈值 **×0.9**，下限回到初值 **0.4%**。持仓期间不衰减。
- maker 成交模型：逐笔跟踪两次轮询间的 tape 窗口高/低；买单窗口最低 ≤ 限价、卖单窗口最高 ≥ 限价即成交于限价（乐观假设：不建模队列/部分成交）。

> 迟滞逻辑：**开在行权价 K、平在 K 的安全侧 threshold 之外**——两者之间保持对冲，避免在 K 附近来回抖动导致频繁开平。

## 关键建模决策（经与需求方确认）

| 项 | 取值 | 说明 |
|---|---|---|
| IV 来源 | 过去 72h **已实现波动率(RV)** 代理 | 滞后、无前视；卖出时固定给该期权定价（不重标） |
| 期权到期 | **30 天** | `GSH_TENOR_DAYS` |
| 对冲方式 | **1:1 全额备兑 on/off, maker 挂单执行** | BBO 外 0.01% 被动挂单、撤单重挂 |
| 对冲触发 | **越过行权价即开 / 回落超过离场阈值即平** | 开在 K、平在 K∓threshold（迟滞） |
| 离场阈值 | 初始 **0.4%**，每次越过 ×1.2，每小时 ×0.9（下限 0.4%） | `GSH_INIT_THRESH / GSH_EXPAND / GSH_DECAY` |
| 每档手数 | 1 张（1 单位标的） | `GSH_NODE_CONTRACTS` |
| 轮询 | 3 秒 | `GSH_POLL_MS` |
| 费用 | 期权 0.03%(名义) / 对冲 0.02%(maker) / 滑点 0 | 滑点作为显式成本，保证已实现与 MTM 口径一致 |

记账（无重复计）：`权益 = 初始 + 已实现 + Σ期权未实现(BS 市值) + Σ备兑腿未实现`。

## 回测结果（ETHUSDT, 2025-04-10 ～ 2026-06-16, 初始 100 万, 每档 1 张）

**当前版本（30 天期权 + 越过行权价开/回落超阈值平, 初始 0.4%）：**

| 指标 | 值 |
|---|---|
| 策略收益 | **−0.74%** |
| Buy & Hold | +7.41% |
| 最大回撤 | **0.93%** |
| 期权卖出 / 到期 | 230 / 220 |
| 对冲挂单 / 成交开 / 成交平 | 7,389 / 2,284 / 2,280 |
| 期权腿已实现 | −191 |
| 对冲腿已实现 | −4,654 |
| 费用 | −3,066 |
| 合计已实现 | −7,911 |

**各版本演进对比：**

| 版本 | 收益 | 回撤 | 费用 | 对冲腿 | 期权腿 | 对冲成交 |
|---|---|---|---|---|---|---|
| v1 逐笔 + taker, 3d, 0.2%/0.24% | −2.49% | 2.49% | −12,342 | −8,688 | −3,853 | 3,577 |
| v2 3s + maker, 3d, 0.2%/0.24% | −2.07% | 2.07% | −9,082 | −7,614 | −4,005 | 6,639 |
| **v3 3s + maker, 30d, 越过开/回落平, 0.4%** | **−0.74%** | **0.93%** | **−3,066** | **−4,654** | **−191** | 2,284 |

**解读**：逐步逼近持平（−2.49% → −2.07% → −0.74%），回撤降到 0.93%。本轮改善来自三点叠加：
1. **30 天期权**：卖出笔数大减（230 vs 832），单张收更多 theta，**期权腿几乎打平（−191）**；
2. **越过行权价开 + 回落超阈值平 + 0.4% 初值**：迟滞更宽，对冲往返从 6,639 降到 2,284，费用从 9.1k 降到 3.1k；
3. maker 低费率延续。

净值曲线对 ETH 价格几乎无感——**市场中性**（回撤 0.93%），但**仍微负**。剩余亏损几乎全在对冲活动：对冲腿 whipsaw −4.7k + 费用 −3.1k ≈ 7.7k，占总亏损 7.9k 的 **~98%**；期权腿已基本打平。要翻正需进一步压低对冲往返成本（更宽 `GSH_INIT_THRESH`、更大 `GSH_MAKER_OFFSET`）或换 IV/tenor 口径以增厚期权腿 edge。

> 注：每档仅 1 张 ETH（约 $2.6k 名义）相对 100 万本金极小，故百分比偏小；损益随手数线性放大。这是按需求原样实现的**如实结果**，非参数寻优后的结论。
